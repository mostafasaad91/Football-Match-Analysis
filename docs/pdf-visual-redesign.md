# PDF visual redesign proposals

The PDF should read as a visual match story, not a sequence of exported charts.
The proposed page order is:

1. Cover: fixture, competition, round, score and one hero control/shot surface.
2. Executive read: four visual cards for control, territory, chance quality and transition threat.
3. Match timeline: possession/control, pressure and xG on one aligned time axis.
4. Progression: pitch entries, lane split and nested possession stages.
5. Pressure and transitions: regain-to-shot, loss consequences and loss maps.
6. Finishing: shot map, outcome breakdown and post-shot value.
7. Player profiles: role-specific Pizza Chart, colored impact map and compact evidence bars.
8. Appendix: definitions, denominators, data coverage and model limitations.

Use one dark cover and one consistent page chrome. Keep chart titles descriptive,
put the takeaway in a short subtitle, and use team color only for team identity.
Use teal, amber and violet only for distinct metric families. Align axes across
pages, show denominators beside rates, and reserve tables for exact lookups.
